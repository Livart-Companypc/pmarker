# pmarker

이미지에 마커를 찍고 좌표를 추출하는 도구입니다.

## ** 사용법 **

1. 마킹이 필요한 이미지 선택
2. 원하는 위치에 '마킹' 표시(드래그가능. 우측 표랑 최종코드에 실시간 반영됨)
3. 해당 상품으로 이동될 수 있는 P코드를 '우측 표'에 입력
4. 최종코드(우측 아래) 쪽에 복사 버튼 누른 후 ctrl+v 해서 제작자에게 전달
